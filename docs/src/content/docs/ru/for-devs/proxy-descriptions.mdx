Prizrak-Box может показывать короткий текст рядом с прокси или прокси группой в списке прокси.
Текст берётся из YAML профиля и выводится рядом с иконкой типа прокси.

---

## Ключи

| Объект | Ключ | Примечание |
|--------|------|------------|
| Прокси (`proxies`) | `serverDescription` | Основной ключ, его записывает панель Remnawave |
| Прокси (`proxies`) | `server_description`, `server-description`, `description` | Запасные, используются в этом порядке, если предыдущего ключа нет или он пустой |
| Группа (`proxy-groups`) | `description` | Единственный ключ для групп |

Используется первое непустое значение. Пробелы в начале и конце удаляются.

```yaml
proxies:
  - name: 🇩🇪 Germany
    type: vless
    serverDescription: Быстрый, 1 Гбит/с
    # ...

proxy-groups:
  - name: 👻 Prizrak
    type: select
    description: Лучшая локация автоматически
    proxies:
      - 🇩🇪 Germany
      - 🇫🇮 Finland
```

---

## Как отображается

- Описание выводится в одну строку рядом с иконкой типа прокси, в строке прокси внутри прокси группы.
- Описание группы показывается так же, в её строке, если группа вложена в другую прокси группу (входит в неё как участник). В списке групп на главном экране оно не показывается.
- Если текст не помещается по ширине, он обрезается с `…`. Полный текст виден во всплывающей подсказке (на мобильных — по долгому нажатию).
- Приложение не ограничивает длину текста. Делайте его не длиннее **30 символов** (лимит поля в панели Remnawave), чтобы он помещался на большинстве экранов.
- Описание приоритетнее текста, который извлекает `ui-subtitle-pattern` на Android.

---

## Ограничения

- Описание получают только прокси из блока `proxies` и группы из `proxy-groups`.
  У прокси, загруженных из `proxy-providers`, описания нет.
