You don't have to understand [routing](/for-devs/routing/) yourself. Ask an AI: it asks what you need and builds the routing or template. At the end it gives a link to import into Prizrak-Box.

## How it works

1. Press the button of the AI you want below. A chat opens with "Read the instructions… My task:".
2. Add in your own words what you need and send it. ChatGPT and Perplexity send the phrase at once — then write the task in the next message. For example:
   - "Russian sites and banks direct, YouTube, Discord and blocked sites via VPN, block ads. My phone is an iPhone."
   - "Everything via the USA, YouTube via Albania, Discord via Belarus, the rest as usual."
3. The AI introduces itself as Glushik and asks a few questions.
4. If you ask for particular countries or servers, the AI asks for a **screenshot of the server list** in Prizrak-Box, to write their names right. Send it.
5. At the end the AI gives a `prizrak-box://…` link. Copy it and in Prizrak-Box open **Templates and Routings → Add → Paste from Clipboard**.

For Claude, sign in before pressing the button, or the phrase is lost. The AI must be able to open links: search or web reading has to be on in the chat. If the AI says it cannot open the link, or you use another AI (DeepSeek, Gemini and so on), copy the prompt below and paste it into the chat whole.

<Aside type="tip">
An AI that can run code and open sites works best. With code it encodes the link right by itself; with sites it checks that the lists it picks exist.
</Aside>

<Aside type="caution">
An AI can be wrong. A rule marked ⚠️ is not from the standard set, and we do not know what is in it. Prizrak-Box checks every rule with the core: a wrong one is left out, with a note on the routing's row.
</Aside>
