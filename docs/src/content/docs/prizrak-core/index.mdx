**Prizrak-Core** is the proxy core that powers Prizrak-Box on every platform. It is based on [mihomo](https://github.com/MetaCubeX/mihomo) (formerly Clash.Meta).

Configurations written for mihomo work in Prizrak-Core unchanged. On top of that, the core adds features that mihomo does not have; they are described below.

- Source code: [legiz-ru/Prizrak-Core](https://github.com/legiz-ru/Prizrak-Core)
- **Download the core:** [latest release](https://github.com/legiz-ru/Prizrak-Core/releases/latest), all versions on the [Releases](https://github.com/legiz-ru/Prizrak-Core/releases) page
- Docker: `ghcr.io/legiz-ru/prizrak-core`

---

## Where to use it

Prizrak-Core ships with Prizrak-Box, but it also works on its own. It is a standalone binary compatible with mihomo, so it can be used anywhere mihomo is used.

- **Prizrak-Box.** The core is built in, nothing to set up.
- **Standalone.** Download the archive for your platform from the [releases](https://github.com/legiz-ru/Prizrak-Core/releases/latest) and run it like regular mihomo: `mihomo -d <folder with config.yaml>`. The Docker image works too.
- **[TrayClash](https://github.com/q0wqex/TrayClash).** A very lightweight Windows app, suitable for Windows 7 devices.
- **[OpenWrt-exodus](https://prettyleaf.github.io/OpenWrt-exodus/).** A tool for routers: OpenWrt, Asus, Keenetic, MikroTik. To install Prizrak-Core specifically, set a special variable during installation; see the OpenWrt-exodus documentation for which one.

## Differences from mihomo

| Feature | mihomo | Prizrak-Core |
|---------|--------|--------------|
| `smart` group (ML-based node selection) | — | ✅ |
| uTLS library | `metacubex/utls` v1.8.8 | `prizrak-utls`: up-to-date uTLS, Chrome 155 / Firefox 148 / Safari 26.3 |
| mux.cool multiplexing (Xray Mux, XUDP) | — | ✅ client and server |
| REALITY with ML-DSA-65, in sync with Xray | — | ✅ |
| XHTTP: HTTP/2 flow governor (`h2-flow`) | — | ✅ (off by default) |
| HTTP/2: 32 KiB send buffer instead of 512 KiB | — | ✅ |
| `freedom`: DIRECT with TLS fragmentation and socket options (Xray-core `freedom`) | — | ✅ |
| `finalmask`: traffic masks from Xray-core (fragment, header-custom, sudoku, xmc, noise, udphop, xdns, xicmp) for vless and trojan | — | ✅ client and server |
| mKCP for VLESS, as in Xray-core since finalmask (xdns DNS tunnels included) | VMess only | ✅ client |
